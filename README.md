# ZeroCrumbs

A web app that helps leftover food reach people who can eat it, instead of ending up in the trash.

Donors register food they have left over. People looking for food mark their allergies and only see what is safe for them. For any available item, the app suggests a recipe based on their tastes.

The interface is in Spanish. Migui, a small animated crumb, is the app's mascot and reacts to what you do.

## Features

- **Register leftover food:** donors enter the dish, how many kilos are left, ingredients, allergens, possible cross-contact, storage, pickup place and the deadline to pick it up.
- **Allergy filter:** people mark their allergies (gluten, shellfish, egg, milk, tree nuts, soy, peanut, fish) and anything else they must avoid. Incompatible food is hidden from their list.
- **Food preferences:** diet type (vegetarian, vegan), preparation time, and foods they like or dislike.
- **Recipe suggestions:** pick an available item and get a recipe adapted to your profile. Right now recipes are generated by local logic; connecting a real AI model is planned.
- **Animations:** page transitions, scroll reveals and list reordering with GSAP (ScrollTrigger and Flip), with support for the system's reduced-motion setting.

## Pages

| Route | Page |
|---|---|
| `/` | Home: explains the three paths (donate, set your allergies, find food) |
| `/donante` | Form to register leftover food |
| `/usuario` | Allergies and food preferences |
| `/comida` | Available food, filtered by your profile |
| `/receta/:id` | Recipe suggestion for a food item |

## Tech stack

- React 19 with Vite
- React Router
- GSAP and `@gsap/react` (ScrollTrigger, Flip)
- CSS Modules
- React Context to share the profile and the published food between pages

## Run it locally

```bash
npm install
npm run dev
```

Other scripts: `npm run build` creates a production build and `npm run lint` runs ESLint.

## Current status

This is a front-end prototype. Data lives in memory: the sample food and anything you publish reset when the page reloads. There is no backend or user accounts yet.
